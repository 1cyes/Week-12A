CLASSIC MINECRAFT UNITY — EMPTY WORLD FIX

This package is for Unity 2022.3 LTS or newer and works with the Universal 3D (URP) template.
It is a simple Minecraft-inspired starter, not an official Minecraft project.

IMPORTANT:
The terrain is generated when you press Play, not while looking at the empty Edit-mode scene.

INSTALL:
1. Extract this ZIP.
2. Open your Unity Universal 3D project.
3. Copy the complete Assets folder from this package into the root of your Unity project.
4. Wait until Unity finishes importing and compiling.
5. The editor script automatically creates Assets/Scenes/ClassicMinecraft.unity.
6. Open Assets/Scenes/ClassicMinecraft.unity.
7. Press Play. You should see the generated voxel terrain and spawn as the player.

IF THE SCENE WAS NOT CREATED:
Use the Unity top menu:
Classic Minecraft > Build or Rebuild Starter Scene
Then open Assets/Scenes/ClassicMinecraft.unity and press Play.

CONTROLS:
WASD = move
Mouse = look
Space = jump
Left click = break block
Right click = place dirt block
Escape = unlock mouse

INPUT SETTING:
If controls do not respond, go to Edit > Project Settings > Player > Other Settings >
Active Input Handling and choose Both. Restart Unity if requested.

If you still see an empty world, check the Console window for red errors and share a screenshot.
